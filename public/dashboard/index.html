Quota trading

An org with spare quota can lend it to the other org for a fixed time. The lender's pool shrinks, the borrower's grows, and the quota goes back on its own when the loan expires.

Borrowed quota can then be leased to raise a rate limit → Rate limiting Every loan is recorded → Audit log

Rate limiting

Each org may send 5 requests every 10 seconds. To go faster, it leases quota from its own pool: every leased unit adds one request per window until the lease ends.

Leases use quota from the pool, so a borrowed pool can lease more → Quota trading

Resilience

Every change is written to PostgreSQL as an event; Redis keeps the running totals so the limiter can answer in under a millisecond. If Redis ever disagrees with the events, a reconciliation job rebuilds it. This runs every 60s, and you can trigger it here.
